## Featured Project: Healthcare Readmission Analytics

**Python · SQL · PostgreSQL · Power BI · Streamlit · pandas · scikit-learn**

An end-to-end, retrospective healthcare analytics portfolio project investigating **30-day hospital readmissions** using the UCI *Diabetes 130-US Hospitals (1999–2008)* dataset.

**What I built**

- Analyzed **101,766 historical hospital encounters** and profiled an **86,547-encounter development cohort** with an observed **11.18%** 30-day readmission rate.
- Created and reconciled **nine PostgreSQL reporting views** for KPIs, demographics, admission patterns, utilization, and data completeness.
- Built a **Power BI executive dashboard** and a **five-page Streamlit application** for interactive research reporting.
- Evaluated **Logistic Regression, Random Forest, and Histogram Gradient Boosting** using patient-aware methods and documented model limitations.

**Evaluation transparency:** The Random Forest's reported ROC-AUC of **0.6494** comes from a **patient-disjoint held-out test partition** that had previously been used for baseline evaluation; it is **not** a strictly untouched, single-use test estimate or external validation. Histogram Gradient Boosting results are based on **patient-grouped out-of-fold development validation**. This is a research and portfolio demonstration, **not a clinical decision-support system**.

**Explore:** [GitHub repository](https://github.com/amoheric/healthcare-readmission-analytics) · [Live interactive dashboard](https://healthcare-readmission-analytics-i3gcjyhxok3hynnwe7trda.streamlit.app) · [Power BI preview](https://github.com/amoheric/healthcare-readmission-analytics/blob/main/docs/screenshots/power_bi_dashboard.png)
